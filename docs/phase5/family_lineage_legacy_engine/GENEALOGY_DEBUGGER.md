# Genealogy Debugger

`FamilyInspector.tree` dibuja el árbol de una familia desde sus fundadores como lo pide la especificación:

```
Familia Takeda (3 generaciones)
├── Takeda Goro (histórico) + Takeda Ume (histórica)
│   └── Takeda Hiro (vivo, adulto, herrero)
│       ├── Takeda Natsu (vivo)
│       └── ...
```

`FamilyInspector.lineageTree` hace lo mismo con los maestros y discípulos de una escuela. `/samuraiai living family tree <npc>` y `/samuraiai living family lineage <nombre>`.
