# Debug

El debug muestra por logs estado de bootstrap, modelo seleccionado, dispositivo,
duración, latencia, error e integridad. Nunca imprime el contenido del audio.
Para probarlo se puede habilitar `voice.debug=true`, abrir el chat y alternar la
tecla V; con el manifest actual el resultado esperado es diagnóstico de modelo
no instalado/runtime no disponible.
