# Performance Suite

Estado: **PARTIAL**. La suite automatizada valida 1.000 solicitudes FIFO sin
pérdidas, cancelación/timeout, 500 runtimes lógicos sin referencias residuales y
el presupuesto cooperativo por tick. El auditor de arranque comprueba además la
capacidad básica de CPU/heap.

Estas pruebas no sustituyen una medición real de TPS, memoria y rutas con
100/250/500 entidades físicas en Minecraft. Esa evidencia continúa pendiente y
por ello no se usa para emitir el certificado `READY`.
