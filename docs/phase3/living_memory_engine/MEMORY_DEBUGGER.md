# Depurador de memoria

`debug/MemoryInspector` + `diagnostics/MemoryDiagnostics`. Comandos: `/samuraiai memory list|search|show|forget|protect|graph|index|export <npc>`. `export` escribe el **snapshot cognitivo** (`MemoryDiagnostics.export`) en `data/samuraiai/exports/`. `mind trace` muestra la cadena de una experiencia.
