# Métricas de memoria

`MemoryMetrics`: creados, descartados, reforzados, fusionados, olvidados, comprimidos, consolidados, recuperados, ecos, reinterpretados, errores (+`lastError`); tiempos de búsqueda, consolidación, observación; razón de compresión; tasa de caché. `/samuraiai memory status`, `/samuraiai mind status`. Medido (300 NPC, 1 800 experiencias): ≈ 314 µs por experiencia en todos los motores.
