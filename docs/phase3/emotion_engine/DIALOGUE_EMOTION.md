# Emoción en el diálogo

`DialogueEmotionEngine.tone`: formalidad, verbosidad, ritmo, probabilidad de silencio, preguntas, calidez y etiqueta de tono de voz (cold/trembling/flat/warm/lively/neutral). Preparado para el Voice Engine; el prompt actual ya recibe las emociones proyectadas en `EmotionState`. `/samuraiai emotion tone <npc>`.
