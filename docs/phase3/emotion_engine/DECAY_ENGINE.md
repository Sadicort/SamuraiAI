# Decaimiento

Curvas (`DecayCurve`): LINEAL, EXPONENCIAL (semivida `exponentialHalfLife`), TRAUMA (semivida enorme y **suelo** `traumaFloorFraction·pico·(1−recuperación)`), HOPE (larga), CUSTOM. Velocidad = regla D de personalidad · técnica/actividad (dormir ×3, meditar ×2,5, hablar ×1,8…) · escala positiva/negativa / (0,5+persistencia). Bajo `minIntensityKeep` la emoción pasa al historial como RECOVERED.
