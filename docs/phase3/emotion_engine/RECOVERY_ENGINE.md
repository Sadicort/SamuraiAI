# Recuperación

Cada trauma tiene su `progress` 0-1 independiente. Fuentes (`RecoverySource`): TIME (`recoveryPerDay`), SLEEP, MEDITATION, FRIENDSHIP, POSITIVE_EVENT, CONVERSATION; el ritmo se multiplica por la resiliencia. ≥ `traumaRecoveredAt` → RECOVERED (`TraumaRecoveredEvent`), el suelo desaparece y **el recuerdo permanece**.
