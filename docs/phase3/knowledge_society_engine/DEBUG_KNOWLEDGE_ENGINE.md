# Depurador

`KnowledgeInspector`: resumen, registros, grafo alrededor de un nodo, rumor con toda su cadena (saltos y transformaciones), comunidad (tradiciones), historia. `KnowledgeEngine.explain` responde **¿por qué cree esto?** (origen, fuente, evidencias, revisiones). Overlay `mind debug`: columnas en los lugares conocidos (verde verificado, amarillo probable, violeta rumor, rojo peligro).
