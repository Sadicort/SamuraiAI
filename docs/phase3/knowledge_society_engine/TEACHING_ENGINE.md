# Enseñanza

`teach(profesor, alumno, temas, respeto, confianza, atención, control de acceso)`: calidad = media ponderada de respeto, confianza, conocimiento del profesor y atención; bajo `teachMinQuality` no se aprende; el alumno nunca sabe más que el profesor (`confianza·calidad·teachConfidenceScale`); los temas restringidos por rango no se enseñan. `KnowledgeTaughtEvent`; `/samuraiai knowledge teach`.
