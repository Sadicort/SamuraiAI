# Aprendizaje

Confianza inicial por método (`confObservation` 0,85, `confExperience` 0,9, `confConversation` 0,6, `confTeaching` 0,75, `confRumor` 0,3, …). Lo **vivido** (directo) se mantiene a plena confianza; lo **contado** se escala por la velocidad de aprendizaje: `1 + learnCuriosity·lean(CURIOSITY) + learnDiscipline·lean(DISCIPLINE)` × atención. Un valor único (`LIVES_AT`, `LEADS`…) que cambia hace perder certeza al anterior (supersede).
