# Amistad

Etapas STRANGER → ACQUAINTANCE → COMPANION → FRIEND → CLOSE_FRIEND → BEST_FRIEND → BROTHER_IN_ARMS. Puntuación = 0,35·confianza + 0,25·afinidad + 0,20·respeto + 0,20·proporción de momentos buenos − 0,25·rivalidad. Cada etapa exige **puntuación, tiempo mínimo** (`friendshipTicksPerStage`) y contactos; **sube una etapa por evaluación**, con histéresis. La última etapa está **preparada pero desactivada** (`brotherEnabled=false`).
