# Honor

Honor **observado** en el otro (50 = neutro), según la lectura cultural del NPC: `SocialEvidence.honorScale` (de `SocietyEngine.honorScale`, p. ej. templo 1,3; guardia 1,4). Categorías (`HonorSystem.category`): HONORABLE, NEUTRAL, QUESTIONABLE, DISHONORABLE, OATH_BREAKER (más juramentos rotos que cumplidos y honor < honorable), LEGENDARY_WARRIOR (honor ≥92 y respeto ≥ MASTER).
Juramentos (`PromiseRecord.Kind.OATH`) llevan la etiqueta `oath` → recuerdo **protegido** del olvido normal.
