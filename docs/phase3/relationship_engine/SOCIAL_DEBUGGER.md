# Depurador social

`debug/SocialInspector` y `RelationshipEngine.explain(npc, objetivo, eje)`: responde **¿por qué este NPC desconfía de mí?** con el valor, el nivel y las causas más fuertes (`kind`, delta, recuerdo, nota con modificadores). Comandos `relationship list|show|timeline|reputation|graph|promise…`, `mind why <npc> trust <persona>`.
